# Модели, зависимости и хранение

[English](Models-and-storage.md) · [ag-media-studio](../../README.md)

## Роли моделей

| Слой | Исполнитель / ограничение |
| --- | --- |
| Текст | Whisper через локальный backend; язык речи и UI независимы |
| Голосовые группы | Sherpa; связи и короткие реплики уточняются отдельными модулями |
| Лица и identity | YuNet + SFace и консервативные связи профилей |
| Видимое говорение | Light-ASD; человек в кадре может молчать, а говорить другой |
| Предметы / текст | NanoDet и OCR backend; метка может меняться между наблюдениями |
| Фигура / взгляд / одежда | Локальные vision/MediaPipe workers по запрошенным слоям |
| Выражения лица | Классификатор видимого выражения, не психологическая оценка |
| Звук и интонация | Платформенные audio backend, включая Apple SoundAnalysis и Zipformer |
| Синтез | Qwen3-TTS и Chatterbox в основном режиме; прежние движки — исследовательские опции |

Это карта ответственности, а не перечень гарантированно установленных моделей. Готовность, пути, backend и разрешённые лицензией сценарии проверяй в текущей конфигурации и `THIRD-PARTY.md`. Fish может работать отдельным локальным сервисом. Первый setup может скачивать веса; документирование не устанавливает модели.

## Данные разных сроков жизни

| Что | Где и зачем |
| --- | --- |
| Постоянные записи и графы | `data/studio` или явно выбранный `--data`; пользовательская история |
| Экспорт и эксперименты | `data/exports`, `data/prosody` и MLflow-хранилище конкретного эксперимента |
| Модели / внешние зависимости | Пути из `voice_paths.py`; совместимые папки Voice Studio на macOS/Windows/Linux |
| Временные кэши | Системный temp, `VOICE_TEMP_DIR`, изоляция по рабочей папке |
| Окружения | `.venv` и `.engines/` с отдельными зависимостями моделей |
| Wiki | Только текст, исходные пути/хэши и условные SVG; без WAV/MP4/фото |

Для очистки используй страницу «Хранилище» и проверяй предложенные пути. Источник, единственный экспорт или установленные веса не становятся временными из-за своего возраста. Переключение имени продукта не переносит и не удаляет эти папки.
