# Изменения, проверки и обновление wiki

[English](Development.md) · [ag-media-studio](../../README.md)

## Порядок изменения

- Через Code Atlas найди владельца функциональности, затем проверь текущий исходник. Карта — статическое свидетельство, не runtime-тест.
- Меняй канонический модуль в `voice_studio/`, сохраняй совместимые launcher-обёртки и tool/schema IDs.
- Проверь тесты затронутого контракта. Для моделей сравнивай одинаковые исходники, seed и режимы, отдельно качество/время/RSS.
- Обнови wiki, если меняются обязанности, входные точки или пользовательский путь.
- Собери и проверь wiki; отдельный reviewer проверяет источники, утверждения и реальные результаты.

## Сборка документации

```text
python3 scripts/build_wiki.py
python3 scripts/build_wiki.py --check
.venv/bin/python -m unittest tests.test_wiki -v
```

Рендерер принимает типизированные блоки: абзац, заголовок, список, таблица, код, ссылка, схема. Raw HTML не выполняется. Ссылки ограничены известными страницами и HTTPS; SVG проверяются на активное содержимое. HTTP отдаёт только файлы из сгенерированного allowlist.

## Границы подтверждения

Генерация и тесты ссылок подтверждают согласованность документации, но не точность моделей и не полную доступность приложения. Статусы старых экспериментов и открытые AG-проверки не превращаются в PASS при переименовании. Текущие ограничения измерений смотри в отчётах рядом с кодом.

## Происхождение оформления

Структура версионируемой wiki следует ag-design `docs/wiki/`: введение → запуск → архитектура → работа агента → проверки. Навигация здесь — нативные ссылки HTML; рисунки — собственные схематичные SVG. Реальные кадры и чужие UI-скриншоты не копируются.
