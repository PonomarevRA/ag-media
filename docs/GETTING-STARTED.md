# Первый запуск AG Media Studio

[English quick start](../README.md) · [Настройка MCP и навыков](AGENT-SETUP.md) · [Сборки для рабочего стола](NATIVE-DISTRIBUTION.md)

## Первый запуск с транскрипцией

Скачай или клонируй репозиторий. Из его корня запусти команду с Python 3.12+.

```sh
python3 -m voice_studio.app.first_run
```

В Windows PowerShell используй `py -3 -m voice_studio.app.first_run`. На macOS
команда может установить недостающие FFmpeg и whisper.cpp через уже установленный
[Homebrew](https://brew.sh/). На Windows и Linux программы `ffmpeg`, `ffprobe`
и `whisper-cli` должны быть доступны в PATH. [FFmpeg](https://ffmpeg.org/download.html) ·
[whisper.cpp](https://github.com/ggml-org/whisper.cpp)

Команда создаёт окружение `.venv`, устанавливает основные библиотеки, скачивает
многоязычный Whisper Base (142 МиБ) и открывает студию. Скачиваемая модель
проверяется по размеру и SHA-256. Если модель уже есть, используется локальный
файл. Рабочая папка и веса находятся вне репозитория. При необходимости укажи
другую рабочую папку через `--data`.

`--prepare-only` выполняет настройку без запуска. `--models-only` скачивает
только веса и подходит, если нативная студия и движки уже установлены.
Синтез, видеоаналитика и дополнительные модели подключаются по необходимости.

## Ручная установка и демонстрационный режим

Склонируй выбранный репозиторий или распакуй архив исходников в отдельную папку. Выполни команды из этой папки. Для проверки интерфейса достаточно Python 3.12+ и базовых зависимостей. Для анализа медиа установи FFmpeg с ffprobe и добавь их в PATH.

**macOS и Linux**

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-core.txt
.venv/bin/python ag_media_studio.py --demo --port 8767
```

**Windows PowerShell**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-core.txt
.\.venv\Scripts\python.exe ag_media_studio.py --demo --port 8767
```

Открой [студию в браузере](http://127.0.0.1:8767/). В демонстрационном режиме синтез выдаёт тестовые тоны. На той же странице можно открыть разделы студии и проверить настройки, а на `/wiki` доступны инструкции по модулям. Выход из запущенного в терминале сервера через Ctrl+C. Если порт занят, выбери свободный и открой адрес из журнала запуска.

## Рабочие материалы

Для реальной обработки убери `--demo`, задай свой порт и укажи внешний каталог с помощью `--data`. Пример для macOS и Linux:

```sh
.venv/bin/python ag_media_studio.py --port 8766 --data "$HOME/AG Media Workspace"
```

В PowerShell используй тот же набор аргументов с `.\.venv\Scripts\python.exe` и путём `"$env:LOCALAPPDATA\AG Media Workspace"`. В каталоге сохраняются материалы, история и анализ. Для MCP укажи этот же каталог как `--studio-data`. Установленную нативную студию запускай из меню приложений. Её локальный порт и MCP-конфигурацию можно узнать через `--print-config`. [Нативная установка и запуск](NATIVE-DISTRIBUTION.md)

| Задача | Что нужно и с чего начать |
| --- | --- |
| Транскрипция, таймкоды и SRT | FFmpeg, whisper-cli и многоязычные веса. Открой «Транскрипция», выбери видео или аудио и оставь автоматический язык либо укажи его явно. |
| Голоса и лица в видео | Включи нужные слои. Для голоса и лица требуются соответствующие модели, перечисленные в настройках и документации. Проверь короткую реплику и карточку спикера. |
| Скриншот, OCR и предметы | В «Транскрипции» открой изображение. Выбери текст, интерфейс или предметы. Для OCR и детекции установи соответствующие движки и модели. |
| Запись и синтез голоса | Разреши микрофон, проверь расшифровку и сохрани запись своего голоса. Для реального синтеза подключи выбранный движок и веса. |
| Граф и работа агента | Подключи MCP к той же студии или открой сохранённый граф локальным MCP. Скриншоты и проверка UI имеют отдельные инструменты. |

Для нестандартной установки задай абсолютные пути к CLI и модели в `VOICE_WHISPER_CLI` и `VOICE_WHISPER_MODEL` до запуска студии. При обычной установке студия находит whisper-cli через PATH и веса в своей папке моделей. Если будешь строить граф из исходника напрямую через MCP, передай те же переменные процессу MCP. На macOS и Linux это можно сделать через `export`, в PowerShell через `$env:ИМЯ = 'путь'`.

`python voice_paths.py models` и `python voice_paths.py dependencies` печатают выбранные каталоги. Их можно переопределить через `VOICE_MODELS_DIR` и `VOICE_DEPENDENCIES_DIR`. Scratch-каталог регулируется `VOICE_TEMP_DIR`. Веса и движки выбираются по потребности. [Движки и модели](wiki/Models-and-storage-ru.md) · [Лицензии ресурсов](../THIRD-PARTY.md)

## Зависимости и веса

При установке из исходников `pip` получает базовые библиотеки из настроенного Python-индекса, обычно PyPI. В нативных сборках эти библиотеки уже упакованы. Модельные движки и веса подключаются отдельно.

| Возможность | Что устанавливается |
| --- | --- |
| Whisper, Tesseract и шумоподавление FFmpeg | Системные программы и локальные файлы моделей. Whisper запускается через `whisper-cli`. |
| Pyannote, ERes2Net и Zipformer Small INT8 | Пакет `sherpa-onnx` и отдельные ONNX-веса. |
| YuNet, SFace, NanoDet, выражения лица и анализ скриншотов | OpenCV и NumPy. Модели OpenCV Zoo подключаются отдельными файлами. |
| Light-ASD и разделение звука MRX/HDemucs | PyTorch и дополнительные пакеты нужного движка. Веса подключаются отдельно. |
| Взгляд, одежда и возраст по внешности | MediaPipe и OpenVINO с соответствующими моделями. |
| Qwen3-TTS и Chatterbox на Apple Silicon, исследовательские F5 и Coqui | `mlx-audio` или отдельные окружения F5 и Coqui. Условия использования весов зависят от модели. |

Из корня исходников можно запустить `python -m voice_studio.synthesis.setup_commercial_voices` в окружении MLX или `python -m voice_studio.synthesis.setup_dub_background` в окружении с зависимостями HDemucs. Эти команды загружают веса для соответствующей функции.

Перед запуском офлайн подготовь выбранные движки и веса. [Сведения об источниках и лицензиях](../THIRD-PARTY.md)

## Если функция недоступна

- Студия открывается, а анализ не стартует. Запусти `ffmpeg -version`, `ffprobe -version` и проверь, что модель и её исполняемый файл доступны процессу студии.
- В меню есть модель, но она не готова. Сверь пути, платформу и зависимости выбранного мода. Запусти короткий пробный анализ после установки.
- MCP подключён, а страницы нет в списке. Открой студию на том же порту, включи MCP Bridge в нужном окне и обнови список через `ui_windows`. [Настройка для агентов](AGENT-SETUP.md)
