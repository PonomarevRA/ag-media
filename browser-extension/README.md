# ag-media-studio Live

Пилот Manifest V3 для Chromium 116+. Он показывает последние распознанные реплики и пронумерованные лица на последнем проанализированном кадре вкладки. Метки времени отсчитываются от запуска захвата. Рамки показывают предыдущий кадр с указанным запаздыванием и исчезают, если кадр устарел.

## Установка

1. Запустите локальную ag-media-studio на `127.0.0.1:8766`. Возьмите токен из `data/studio/live-token.txt` или используйте установленный при запуске `VOICE_LIVE_TOKEN`.
2. Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите каталог `browser-extension`.
3. Откройте отдельную вкладку с видео. Нажмите значок **ag-media-studio Live**, введите токен, выберите язык речи и нажмите **Начать анализ вкладки**.
4. Остановите захват кнопкой расширения. Закрытие или обычная перезагрузка вкладки тоже завершают сессию.

Для проверки сначала подойдёт локальное видео в браузере, затем общедоступные ролики YouTube или Instagram. Данные передаются только локальной студии и сами видеозаписи расширением не сохраняются. Источник — изображение и звук выбранной вкладки, включая видимую разметку страницы. Во весь экран через сам HTML-элемент видео браузер может скрыть наложение.

## Режим пилота

- Захват ограничен 640×480 и 8 FPS. Независимые фрагменты VP8/Opus передаются примерно каждые 3 секунды. Пока запрос обрабатывается, следующий готовый фрагмент может быть пропущен.
- Захват вкладки переключает её звук на MediaStream. Расширение воспроизводит этот поток локально через AudioContext.
- Речь и рамки показываются независимо. Определение активного говорящего и склейки автономного анализа Light-ASD не выполняются в этом режиме.
- Жест запуска и локальный токен обязательны. Расширение не запрашивает постоянный доступ к YouTube, Instagram или другим сайтам.

## Проверка расширения

Из `voice-studio` с установленными `node`, `npm` и `ffprobe`:

```sh
check_dir="$(mktemp -d)"
npm install --prefix "$check_dir" playwright
"$check_dir/node_modules/.bin/playwright" install chromium
VOICE_PLAYWRIGHT="$check_dir/node_modules/playwright/index.mjs" node browser-extension/test/smoke.mjs
```

Если Chromium уже установлен в другом месте, передайте путь к исполняемому файлу через `VOICE_CHROMIUM`. Проверка подменяет выдачу доступа к вкладке и локальный сервер. Запись WebM, пересылка фрагментов, отображение на вкладке и остановка выполняются расширением в Chromium.

Для проверки реального локального API на macOS добавьте `VOICE_LIVE_INTEGRATION=1` к той же команде. Она использует `say` и `ffmpeg` для синтетической английской речи, отправляет записанный Chromium фрагмент в запущенную студию и проверяет транскрипцию и временные метки. Используется токен из файла студии или `VOICE_LIVE_TOKEN`. Для изолированной проверки укажите порт отдельного экземпляра студии в `VOICE_LIVE_PORT` и передайте его токен в `VOICE_LIVE_TOKEN`.
