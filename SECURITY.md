# Security reports

Do not put credentials, private media, transcripts, voice references or model
files in public issues. Use the repository owner's private reporting channel.
No public contact address or external reporting service is configured in this
source package.

The application runs local tools and optional model workers with the current
user's permissions. Review model sources and commands before installation.
Source export scans selected text for common credential and local-account
patterns; it does not replace a source review or dependency audit.
